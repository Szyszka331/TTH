# Time4Heroes Build 3.2 — Map Fragments & Hidden Places

- Zaginione skrawki mapy mogą wypadać z potworów, elit, bossów i skrzyń w lochach.
- 4 skrawki automatycznie składają się w mapę i ujawniają ukrytą lokację.
- Losowane ukryte miejsca: skarb, obozowisko potworów albo wejście do nieodkrytego lochu.
- Obozowisko generuje 3–5 przeciwników dopasowanych do poziomu gracza; ostatni jest elitą.
- Ukryty skarb daje złoto, materiały i szansę na sprzęt.
- Ukryte wejście przenosi wejście do istniejącego nieodkrytego lochu i zachowuje system strażnika.
- Dziennik Odkrywcy pokazuje liczbę skrawków i ukończonych miejsc z map.
- Zachowane wszystkie mechaniki z 3.1.
