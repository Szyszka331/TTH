# GeoRPG — Build 0.3

**Visual & Combat Overhaul** — duża aktualizacja prototypu GeoRPG.

## Co nowego w 0.3
- pełnoekranowa scena walki zamiast małego okna,
- nowy ekran postaci z układem wyposażenia typu paper-doll,
- 9 slotów ekwipunku: broń, hełm, pancerz, rękawice, buty, amulet, 2 pierścienie i druga ręka,
- rozgałęzione drzewka umiejętności dla wszystkich 5 klas,
- więcej sprzętu i czytelniejsze rzadkości przedmiotów,
- rozbieranie niepotrzebnego sprzętu na złom,
- rozbudowany ekran chowańców,
- nowy hub Wioski Startowej i klimatyczne wnętrza usług,
- filtry mapy: potwory / miejsca / lochy,
- bardziej czytelne znaczniki mapy i aktywny cel questa,
- 15 typów potworów w puli świata,
- poprawiony loot z elit,
- automatyczna migracja zapisów z Build 0.2 i 0.1,
- eksport zapisu jako `georpg-build-0.3-save.json`.

## GitHub Pages
Wgraj **bezpośrednio do głównego katalogu repozytorium** i zastąp stare pliki:

- `index.html`
- `app.js`
- `data.js`
- `styles.css`
- `README.md`

Nie twórz folderu `js`. `index.html` ładuje `app.js` z katalogu głównego.
